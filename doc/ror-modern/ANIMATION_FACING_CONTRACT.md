# Контракт действий, направлений и анимации

Актуально с: 2026-09-12  
Владелец: I5

## Граница ответственности

Симуляция определяет задачу, фазу действия, `movement_facing`, `desired_facing`, `action_facing`, момент attack event, урон и смерть. Presentation выбирает исходный клип и кадр по этим данным, но не изменяет результат действия.

`facing` временно остаётся совместимым presentation-полем. При движении оно следует `movement_facing`, при работе/атаке — зафиксированному `action_facing`, после контакта может восстановиться из направления формации.

## Логические направления

| Индекс | Метка | World vector | Source block | Mirror |
|---:|---|---:|---:|:---:|
| 0 | S  | `( 1, 1)` | 0 | нет |
| 1 | SW | `( 0, 1)` | 1 | нет |
| 2 | W  | `(-1, 1)` | 2 | нет |
| 3 | NW | `(-1, 0)` | 3 | нет |
| 4 | N  | `(-1,-1)` | 4 | нет |
| 5 | NE | `( 0,-1)` | 3 | да |
| 6 | E  | `( 1,-1)` | 2 | да |
| 7 | SE | `( 1, 0)` | 1 | да |

Проверка реальных кадров Clubman подтверждает сохранённый в SLP порядок `S, SW, W, NW, N`. Восточные направления получаются отражением. Единственная функция преобразования — `FacingConvention.logical_for_world`; рендер и симуляция не имеют собственных таблиц углов.

## Фазы и клипы

- `idle`, `move/approach`, `gather`, `carry`, `build`, `repair`, `attack windup`, `attack recover`, `die`, `decay` задаются авторитетным состоянием.
- Переход `AttackWindup -> AttackRecover` не перезапускает тот же attack clip: время и одноразовые frame events продолжаются.
- Только начало нового цикла `Recover -> Windup` явно перезапускает attack clip.
- Attack/death/corpse descriptors не зацикливаются.
- Удар или выпуск снаряда определяются simulation event marker из нормализованных данных. Частота отрисовки не может добавить или потерять урон.

## Доказательства

- `test_facing_convention.gd` проверяет восемь направлений, source block и mirror.
- `test_animation_controller.gd` проверяет переходы, прерывания и непрерывность клипа.
- `test_animation_events.gd` проверяет однократные damage/projectile/death markers.
- `test_animation_direction_pipeline.gd` использует реальные 75 кадров Clubman, проверяет все направления и отсутствие обратного хода кадров на границе windup/recover.
